# Генератор конфигов CDN

**Мультипликатор конфигов Xray и генератор ссылок CDN**

[English](README.md) | [فارسی](README.fa.md) | [中文](README.zh.md)

Браузерное SPA, которое берёт сырые конфиги Xray (VLESS / VMESS / Trojan), умножает их по IP-адресам CDN, портам и TLS-настройкам — создавая расширенный список готовых к использованию ссылок.

## Возможности

- **Ввод:** вставка сырых конфигов и списка IP/доменов CDN
- **Переключение TLS / без TLS** — оба режима с независимым выбором портов
- **Расширенные настройки TLS:**
  - Множественный выбор ALPN (h3, h2, http/1.1 и комбинации)
  - Множественный выбор отпечатков (chrome, firefox, safari, edge, android, random, randomized)
  - Случайный SNI (8-12 случайных символов + корневой домен + точка, обход FQDN)
- **Вывод:** копировать всё в буфер обмена или скачать `.txt`
- **Выбор темы:** Светлая / Тёмная / Системная
- **Многоязычность:** английский, فارسی (персидский), русский, 中文 (китайский) — поддержка RTL для персидского
- **Неблокирующая работа:** индикатор прогресса, браузер не зависает

## Стек

- Vue 3 + Vite + Tailwind CSS + vue-i18n
- Vitest для модульных тестов
- Одностраничное приложение (без SSR)

## Разработка

```bash
npm install
npm run dev     # сервер разработки
npm run build   # production-сборка
npm test        # запуск тестов
```
