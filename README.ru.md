# Генератор конфигов CDN

**Мультипликатор конфигов Xray и генератор ссылок CDN**

[English](README.md) | [فارسی](README.fa.md) | [中文](README.zh.md)

Браузерное SPA, которое берёт сырые конфиги Xray (VLESS / VMESS / Trojan), умножает их по IP-адресам CDN, портам и TLS-настройкам — создавая расширенный список готовых к использованию ссылок.

## Возможности

- **Ввод:** вставка сырых конфигов и списка IP/доменов CDN
- **Переключение TLS / без TLS** — оба режима с независимым выбором портов
- **Расширенные настройки TLS:**
  - Множественный выбор ALPN (h3, h2, http/1.1 и комбинации)
  - Множественный выбор отпечатков (chrome, firefox, safari, edge, android, random, randomized)
  - Случайный SNI (8-12 случайных символов + корневой домен + точка, обход FQDN)
- **Вывод:** копировать всё в буфер обмена или скачать `.txt`
- **Выбор темы:** Светлая / Тёмная / Системная
- **Многоязычность:** английский, فارسی (персидский), русский, 中文 (китайский) — поддержка RTL для персидского
- **Неблокирующая работа:** индикатор прогресса, браузер не зависает

## Как использовать

### 1. Ввод сырых конфигов

Вставьте ссылки конфигов Xray в поле **Raw Configs**, по одной на строку. Поддерживаемые форматы:

```
vless://uuid@example.com:443?type=ws&security=tls&path=%2F#my-server
trojan://password@example.com:443?type=ws&security=tls&sni=sni.example.com#trojan-box
vmess://eyJ2IjoiMiIsInBzIjoibSIsImFkZCI6...
```

**Примечание:** Обрабатываются только конфиги с типом транспорта `ws`, `xhttp`, `httpupgrade` или `grpc`. Остальные проходят без изменений.

### 2. Ввод списка CDN

Введите IP-адреса или домены CDN в поле **CDN List**, по одному на строку:

```
1.1.1.1
2.2.2.2
cdn.example.com
```

**Важно:** Указанные хосты CDN должны быть способны проксировать трафик для домена из вашего исходного конфига. Сгенерированные ссылки заменяют исходный адрес на хост CDN, сохраняя ваш исходный домен в параметрах `host` и `sni` — поэтому CDN должен быть настроен на маршрутизацию запросов для вашего домена к вашему исходному серверу.

### 3. Настройки

- **TLS / без TLS:** Включите/выключите каждый режим. Хотя бы один должен быть активен.
- **Порты:** Выберите порты для каждого активного режима (по умолчанию без TLS: 80, TLS: 443). Требуется хотя бы один порт для активного режима.
- **Расширенные настройки TLS (когда TLS включён):**
  - **ALPN:** Выберите один или несколько протоколов (h3, h2, http/1.1 или комбинации). Требуется хотя бы один.
  - **Fingerprint:** Выберите один или несколько отпечатков (chrome, firefox, safari, edge, android, random, randomized). Требуется хотя бы один.
  - **Случайный SNI:** Заменяет SNI на 8-12 случайных символов + корневой домен + точка (обход FQDN).

### 4. Генерация

Нажмите **Generate**. Индикатор прогресса показывает обработку каждого конфига. Браузер не зависает.

### 5. Вывод

- **Copy All:** Копирует все сгенерированные ссылки в буфер обмена.
- **Download .txt:** Сохраняет все ссылки в файл `.txt`.

### Пример

**Ввод (сырой конфиг):**
```
vless://a1b2c3d4@shop.ir:443?type=ws&security=tls&path=%2Fconnect#cdn-node
```

**Список CDN:**
```
1.1.1.1
2.2.2.2
```

**Настройки:** TLS вкл, порт 443, ALPN: h2, Fingerprint: chrome, Случайный SNI: выкл

**Сгенерированный вывод (2 ссылки):**
```
vless://a1b2c3d4@1.1.1.1:443?type=ws&security=tls&path=%2Fconnect&host=shop.ir&sni=shop.ir&alpn=h2&fp=chrome&insecure=0&allowInsecure=0#cdn-node-001
vless://a1b2c3d4@2.2.2.2:443?type=ws&security=tls&path=%2Fconnect&host=shop.ir&sni=shop.ir&alpn=h2&fp=chrome&insecure=0&allowInsecure=0#cdn-node-002
```

## Стек

- Vue 3 + Vite + Tailwind CSS + vue-i18n
- Vitest для модульных тестов
- Одностраничное приложение (без SSR)

## Разработка

```bash
git clone https://github.com/rahgozar94725/CDN-Config-Generator.git
cd CDN-Config-Generator
npm install
npm run dev     # сервер разработки
npm run build   # production-сборка
npm test        # запуск тестов
```

Откройте `http://localhost:5173` в браузере. Для развёртывания используйте любую статическую файловую раздачу с папкой `dist/`.
