# تولیدکننده کانفیگ CDN

**تکثیرکننده کانفیگ Xray و تولیدکننده لینک CDN**

[English](README.md) | [Русский](README.ru.md) | [中文](README.zh.md)

یک SPA مبتنی بر مرورگر که کانفیگ‌های خام Xray (VLESS / VMESS / Trojan / Shadowsocks) را دریافت کرده و با ترکیب IPهای CDN، پورت‌ها و تنظیمات TLS، لیست گسترده‌ای از لینک‌های آماده استفاده تولید می‌کند.

**نمایش زنده:** [https://rahgozar94725.github.io/CDN-Config-Generator/](https://rahgozar94725.github.io/CDN-Config-Generator/)

## قابلیت‌ها

- **ورودی:** چسباندن کانفیگ‌های خام و لیست IP/دامین CDN
- **فیلد ساب‌دامین CDN:** ساب‌دامین مسیریابی هر کانفیگ، پر شدن خودکار و قابل ویرایش، با قابلیت اعمال به همه
- **بررسی سازگاری:** کانفیگ‌هایی که از CDN رد نمی‌شوند با ذکر دلیل فهرست می‌شوند، به خروجی نمی‌رسند، و تکی یا یکجا قابل حذف‌اند
- **تغییر حالت TLS / بدون TLS** — هر دو حالت با انتخاب پورت مستقل
- **تنظیمات پیشرفته TLS:**
  - انتخاب چندگانه ALPN (h3, h2, http/1.1 و ترکیبات)
  - انتخاب چندگانه Fingerprint (chrome, firefox, safari, edge, android, random, randomized)
  - SNI تصادفی (8-12 کاراکتر تصادفی + دامین ریشه + نقطه انتهایی)
- **خروجی:** کپی همه در کلیپ‌بورد یا دانلود به‌صورت `.txt`
- **پوسته انتخابی:** روشن / تاریک / سیستمی
- **چندزبانه:** انگلیسی، فارسی، روسی، چینی — پشتیبانی از RTL برای فارسی
- **غیرمسدودکننده:** نوار پیشرفت در حین تولید، بدون هنگ کردن مرورگر

## نحوه استفاده

### 1. ورودی کانفیگ‌های خام

لینک‌های کانفیگ Xray را در فیلد **کانفیگ‌های خام** وارد کنید، هر خط یک لینک. فرمت‌های پشتیبانی‌شده:

```
vless://uuid@example.com:443?type=ws&security=tls&path=%2F#my-server
trojan://password@example.com:443?type=ws&security=tls&sni=sni.example.com#trojan-box
vmess://eyJ2IjoiMiIsInBzIjoibSIsImFkZCI6...
ss://YWVzLTI1Ni1nY206cGFzc3dvcmQ@example.com:443?type=ws&security=tls#ss-box
```

**چه چیزی از CDN رد می‌شود.** یک کانفیگ فقط وقتی بازنویسی می‌شود که هر سه شرط برقرار باشند:

- ترنسپورت یکی از این‌ها باشد: `ws`، `xhttp`، `grpc`، `httpupgrade`
- امنیت ترنسپورت `none` یا `tls` باشد — روش REALITY از CDN رد نمی‌شود
- کانفیگ `flow` نداشته باشد، یا آن را همراه با رمزنگاری VLESS اعلام کرده باشد

هر چیز دیگری یک ردیف می‌گیرد که دلیل کنار گذاشته شدنش را توضیح می‌دهد، و به خروجی نمی‌رسد. هر ردیف دکمه حذف دارد، و یک دکمه همه ردیف‌های کنارگذاشته‌شده را یکجا برمی‌دارد. اگر یک ساب‌اسکریپشن مخلوط چسبانده‌اید و می‌خواهید خط‌های دست‌نخورده هم در همان لیست برگردند، گزینه **کانفیگ‌های کنارگذاشته‌شده در خروجی بیایند** را روشن کنید.

شدوساکس در گویش بومی Xray خوانده می‌شود، یعنی همان‌جایی که ترنسپورت در query string اعلام می‌شود، درست مثل VLESS. فرم قدیمی‌تر `plugin=` پشتیبانی نمی‌شود: نه ALPN را می‌تواند حمل کند نه fingerprint را، و SNI آن به ساب‌دامین مسیریابی قفل است.

### 2. ورودی لیست CDN

آدرس‌های IP یا دامین‌های CDN را در فیلد **لیست CDN** وارد کنید، هر خط یک مورد:

```
1.1.1.1
2.2.2.2
cdn.example.com
```

**مهم:** هاست‌های CDN که وارد می‌کنید باید بتوانند ترافیک ساب‌دامین مسیریابی شما را پروکسی کنند. لینک‌های تولیدشده آدرس اتصال را با هاست CDN جایگزین می‌کنند و مقدار فیلد ساب‌دامین CDN را در پارامتر `host` می‌نویسند — بنابراین CDN باید برای هدایت درخواست‌های آن ساب‌دامین به سرور مبدأ پیکربندی شده باشد.

### 3. ساب‌دامین CDN

پس از چسباندن کانفیگ‌ها، هر کانفیگ سازگار به‌صورت یک ردیف با فیلد **ساب‌دامین CDN** نمایش داده می‌شود؛ ردیف‌های کنارگذاشته‌شده به‌جای فیلد، دلیلشان را نشان می‌دهند. این فیلد هویت مسیریابی را در پارامتر `host` لینک‌های تولیدشده قرار می‌دهد، و وقتی TLS روشن باشد در `sni` هم — مقداری که CDN برای هدایت ترافیک به سرور مبدأ شما استفاده می‌کند.

**ترتیب پر شدن خودکار:**
1. پارامتر `host` صریح از کانفیگ اصلی (اولویت دارد)
2. آدرس اتصال، اگر به‌جای IP یک هاست باشد
3. در غیر این صورت خالی — باید آن را پر کنید

**فیلد الزامی:** وقتی آدرس اتصال IP است و پارامتر `host` وجود ندارد، فیلد خالی است و تولید با خطای هر ردیف مسدود می‌شود. ساب‌دامین مسیریابی (مثلاً `sub.example.com`) را وارد کنید.

**اعمال به همه:** از ورودی «اعمال به همه» برای پر کردن همه ردیف‌ها با یک مقدار در یک کلیک استفاده کنید.

### 4. تنظیمات

- **TLS / بدون TLS:** هر کدام را روشن/خاموش کنید. حداقل یکی باید فعال باشد.
- **پورت‌ها:** برای هر حالت فعال، پورت‌ها را انتخاب کنید (پیش‌فرض بدون TLS: 80، TLS: 443). حداقل یک پورت برای هر حالت فعال الزامی است.
- **تنظیمات پیشرفته TLS (وقتی TLS فعال است):**
  - **ALPN:** یک یا چند پروتکل انتخاب کنید (h3, h2, http/1.1 یا ترکیبات). حداقل یکی الزامی است.
  - **Fingerprint:** یک یا چند fingerprint انتخاب کنید (chrome, firefox, safari, edge, android, random, randomized). حداقل یکی الزامی است.
  - **SNI تصادفی:** با فعال‌سازی، SNI با 8-12 کاراکتر تصادفی + دامین ریشه + نقطه انتهایی جایگزین می‌شود (دور زدن FQDN).
- **کانفیگ‌های کنارگذاشته‌شده در خروجی بیایند:** به‌صورت پیش‌فرض خاموش است، پس خروجی فقط لینک‌های تولیدشده را دارد. با روشن کردنش، متن اصلی هر ردیف کنارگذاشته‌شده دست‌نخورده در خروجی کپی می‌شود.

### 5. تولید

روی **تولید** کلیک کنید. نوار پیشرفت وضعیت پردازش را نشان می‌دهد. مرورگر هنگ نمی‌کند.

### 6. خروجی

- **کپی همه:** همه لینک‌های تولیدشده را در کلیپ‌بورد کپی می‌کند.
- **دانلود فایل txt:** همه لینک‌ها را به‌صورت فایل `.txt` ذخیره می‌کند.

### مثال

**ورودی (کانفیگ خام):**
```
vless://a1b2c3d4@shop.ir:443?type=ws&security=tls&path=%2Fconnect#cdn-node
```

**لیست CDN:**
```
1.1.1.1
2.2.2.2
```

**تنظیمات:** TLS روشن، پورت 443، ALPN: h2، Fingerprint: chrome، SNI تصادفی: خاموش

**ساب‌دامین CDN:** به‌صورت خودکار `shop.ir` پر می‌شود (آدرس اتصال به‌جای IP یک هاست است، بدون پارامتر `host` صریح).

**خروجی تولیدشده (2 لینک):**
```
vless://a1b2c3d4@1.1.1.1:443?type=ws&security=tls&path=%2Fconnect&host=shop.ir&sni=shop.ir&alpn=h2&fp=chrome&insecure=0&allowInsecure=0#cdn-node-001
vless://a1b2c3d4@2.2.2.2:443?type=ws&security=tls&path=%2Fconnect&host=shop.ir&sni=shop.ir&alpn=h2&fp=chrome&insecure=0&allowInsecure=0#cdn-node-002
```

## تکنولوژی

- Vue 3 + Vite + Tailwind CSS + vue-i18n
- Vitest برای تست‌های واحد
- برنامه تک‌صفحه‌ای (بدون SSR)

## توسعه

```bash
git clone https://github.com/rahgozar94725/CDN-Config-Generator.git
cd CDN-Config-Generator
npm install
npm run dev     # سرور توسعه
npm run build   # ساخت نسخه نهایی
npm test        # اجرای تست‌ها
```

مرورگر را در `http://localhost:5173` باز کنید. برای استقرار، پوشه `dist/` را با هر سرور فایل استاتیک سرو کنید.
