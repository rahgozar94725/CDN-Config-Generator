# CDN-Config-Generator

## Agent skills

### Issue tracker

Issues live as GitHub issues (gh CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles map to default label strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at repo root. See `docs/agents/domain.md`.

### Documented solutions

`docs/solutions/` — solutions to past problems, by category, with YAML frontmatter (`module`, `tags`, `problem_type`). Relevant when implementing or debugging in an area one covers.

### Persian style

Register, orthography and RTL rules for `fa.json` and `README.fa.md`. See `docs/agents/persian-style.md`.
